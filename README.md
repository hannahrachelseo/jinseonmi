# Hannah's ToDo

진·선·미·일 투두 & 습관 앱

오늘 할 일을 **진(眞) · 선(善) · 미(美) · 일(業)** 로 나눠 관리하고, 매일 하는 습관을 쌓아가는 웹앱이에요.
휴대폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 기능
- 이번 주 운동회 · 월간 마라톤: 영역별로 목표를 여러 개 세우고 친구들이 트랙을 달리며 진행률 표시 (완주 시 주간 +50P, 월간 +150P)
- 진·선·미·일·기타 배너별 오늘 할 일, 체크 / 체크 취소, ‘내일로’ 미루기(되돌리기 가능)
- 전날 못 한 일은 다음 날 오전 7시에 자동 정리 (‘내일로’ 미룬 일은 남음)
- 습관은 매일 자동으로 해당 영역 배너에 들어가요 (추가·수정·삭제)
- 캘린더에서 날짜를 눌러 미래 할 일 미리 적기, 1년(12달) 한눈에 보기 + 올해 레이스 기록
- 성취율: 일 · 주 · 월 · 3개월 · 6개월 · 1년
- 포인트: 하루 100% +30P, 습관 7일 연속 +100P, 3일 미수행 −50P, 회복 미션 +25P, 쉬는 날 쿠폰 월 2장
- 한 줄 일기 · 기분 · 사진/영상 첨부
- 나중에 볼 것 보관함 (대화법 / 연애 / 재테크 / 자기관리·계발): 링크 + 메모 + 체크리스트
- 매일 오전 7시에 바뀌는 오리지널 캐릭터 10종

## 데이터
모든 기록과 사진은 **이 기기 브라우저 안에만** 저장돼요. 서버로 보내지 않아요.
폰을 바꿀 땐 ‘도전 & 회복’ 화면 맨 아래 **백업 파일 저장 → 새 폰에서 백업 불러오기**를 쓰세요. 사진·영상도 함께 옮겨져요.

## 안드로이드 APK
`main`에 푸시하면 GitHub Actions가 APK를 만들어 Releases에 올려요.
항상 최신 파일: https://github.com/hannahrachelseo/jinseonmi/releases/latest/download/HannahsToDo.apk

## 자동 배포
`main`에 푸시하면 GitHub Actions가 `app/` 폴더를 GitHub Pages에 올려요.
처음 한 번만: 저장소 **Settings → Pages → Source** 를 **GitHub Actions** 로 바꿔주세요.
